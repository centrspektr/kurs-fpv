# Готовые модели и текстуры модуля 3

Все файлы здесь - бесплатные, лицензия CC0 (общественное достояние): можно для учёбы и для продажи курса, указывать автора не обязательно, но мы указываем.

Предметы (папки с именем модели) и текстуры (папка tekstury/) - Poly Haven, https://polyhaven.com (CC0):
- metal_office_desk - стол; desk_lamp_arm_01 - лампа; retro_multimeter - мультиметр; metal_stool_01 - табурет;
- tool_cart - тележка; steel_frame_shelves_01 - стеллаж; plastic_crate_01 - ящик; cardboard_box_01 - коробка;
- metal_tool_chest - ящик для инструментов; power_box_01 - щиток; wall_clock - часы; mounted_fluorescent_lights - лампы; SchoolChair_01 - стул;
- текстуры: garage_floor (пол комнат), painted_plaster_wall (стены комнат).

Двери коридора (папка kenney/) - Kenney Space Station Kit, https://kenney.nl (CC0), см. kenney/License.txt.

Текстуры уменьшены до 512 точек, чтобы модуль быстро грузился на телефоне.
